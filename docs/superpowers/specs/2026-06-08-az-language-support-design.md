# Design Spec: Azerbaijani Language Support

## Goal
Add full Azerbaijani ("az") localization support to the Ghost theme by introducing a new localization file `locales/az.json`.

## Requirements
- Support Azerbaijani as a target language.
- Ensure all localization strings mapped in standard `locales/en.json` and custom/enhanced `locales/tr.json` are fully translated.
- Maintain consistency with existing internationalization (i18n) patterns in the theme.

## Translation Source & Reference
To ensure idiomatic translation, Turkish localization (`locales/tr.json`) was used alongside English (`locales/en.json`) as Azerbaijani and Turkish are closely related Turkic languages and share highly parallel terminology structures for modern web applications.

## File to Create
- `locales/az.json`
